# Charaktere

Master-Prompts für GLOW, FLEX, SNOOZY und DAILY. Jeder Prompt ist komplett, du musst nichts aus den Bausteinen dazukopieren.

**Immer mit hochladen:** das Charakterbild `R-BÄR-<SORTE>` (`assets/characters/<sorte>.webp`). Wenn du das Character-Bible-Board der Sorte hast (`R-BIBLE-<SORTE>`), lade es als zweites Bild dazu: Seitenansichten und Mimik werden dann deutlich treuer.

Pro Bär gibt es die gleichen acht Prompts, damit du schnell vergleichen kannst:

| Nr. | Wofür |
| --- | --- |
| 01 | Master: freigestellter Bär in neuer Pose (Ausgangsbild für alles andere) |
| 02 | Mimik-Sheet mit sechs Ausdrücken (für Reaktionen, Sticker, Videos) |
| 03 | Bär präsentiert seine Dose (Studio, Sortenhintergrund) |
| 04 | Bär in seiner Alltagsszene, fotorealistisch |
| 05 | Charakterkarte für die Box |
| 06 | Sticker mit weißem Rand |
| 07 | Black-Week-Look |
| 08 | Running-Gag-Motiv mit Text |

Unten folgen die Crew-Prompts (`C-CREW-…`) mit mehreren Bären in einem Bild.
